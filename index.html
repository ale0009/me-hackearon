Cómo se hizo

Revisa una web

1. Arrastra este botón a tu barra de favoritos:

¿Me hackearon?

2. Abre la web que quieres revisar y pulsa el favorito. Se abrirá esta página con el informe.

El marcador lee la página tal como llega del servidor y tal como se ve, sus cabeceras y tres rutas públicas de WordPress (/wp-json/wp/v2/users, /xmlrpc.php, /readme.html). Todo pasa en tu navegador: nada se envía a otro servidor.

¿En el celular, o el sitio bloquea el marcador? Usa «Pegar el código».

Cada noche, GitHub Actions revisa una lista de sitios dos veces: como navegador y como Googlebot. Así detecta el spam que el atacante solo le muestra al buscador. Si un sitio empeora, abre un issue que llega por correo, y lo cierra cuando se limpia.

Cargando la última vigilancia…

Para vigilar tus sitios: haz un fork del repositorio, mejor privado, y pon tus direcciones en vigilancia/sitios.txt. Aquí solo se vigilan sitios propios del autor: revisar públicamente webs ajenas sería divulgar sus fallas.

    Avisa al dueño

    Borrador de aviso responsable. Revísalo, agrega tu firma y envíalo al correo de contacto del sitio.

    Revisión pasiva: solo lee lo que la web entrega a cualquier visitante. No prueba contraseñas ni explota fallas. Desde afuera no se ven las puertas traseras del servidor: si hay signos de infección, revisa también por dentro, con un escáner como Wordfence o Sucuri. Usa la herramienta en sitios propios o para avisar de buena fe a sus dueños.
